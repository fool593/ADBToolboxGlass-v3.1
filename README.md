# ADB 工具箱（ADBToolboxGlass）v3.1

一个面向**自有设备**的 Android 系统工具箱：不用电脑也能完成性能调优、按游戏改帧率、插件/模块管理、
系统还原、安全护盾（全盘恶意脚本扫描），甚至内核级提权。核心纪律：
**所有系统级命令真实执行并回读验证；删除与破坏性操作永远由你逐条确认，应用绝不自动执行。**

> **当前版本：v3.1**（版本定义：androidApp/build.gradle.kts → `versionName = "3.1"` / `versionCode = 31`）。
> 安装包见 [Releases](https://github.com/fool593/ADBToolboxGlass-v3.1/releases) 页 `ADBToolboxGlass-v3.1-.-release.apk`（正式签名）。

## 功能一览

| 类别 | 内容 |
|---|---|
| 🚀 性能优化 | 16 品牌独立分类（小米/华为/vivo/iQOO…），Root/ADB 分行；通用 26 条 + 华为 30 条，真实命令+验证+回读；手机体检；**一键还原全部系统默认**（47 键 + 27 组件） |
| 🎮 游戏 | 全局刷新率最高 165Hz；**按游戏单独配帧率**（游戏进前台自动切换）；非华为免 ADB/免 root，华为走 ADB；可选系统级限帧（Android 13+） |
| 🔧 ADB / 模块 | 终端、Shell 执行器、ADB 面板（重启/关机/**强开网络 ADB**）、插件与 Root 模块管理（Magisk/KSU）、自带 WebUI 可远程调试 |
| 🛡 安全 | **安全护盾**：root 全盘扫恶意脚本（删相册/删全机/混淆链），只列出、删除须逐条确认；三项授权页（Shizuku/无障碍/Root）真实状态 |
| ⚡ 提权 | 内核提权：内置 68 个 vivo 内核偏移表 + **arm64 GhostLock 原生二进制**（官方 NDK r29 编译）+ `su` uid=0 真实判定；一键 Root 自动重试（10 次/可停止） |
| ✨ 个性化 | 首次设置向导、3 套主题（国庆/华为/经典，持久化）、开屏动画开关、玻璃参数调节、三语言（中/英/印地） |

## 特色
- **事事先问人**：护盾扫描、还原、删除——一律"列出 → 你确认 → 才执行"，拒绝"一键假优化"；
- **每条命令可回读验证**：失败按 15+ 错误码分类 + 原始 stderr，不做假成功；
- **端到端真实提权链路**：偏移表 + 二进制 + 执行 + uid=0 判定，表外内核按设计拒绝（不强配机型）；
- **免电脑**自给自足：无电脑强开 ADB、按游戏自动切帧率；
- **稳定版**：正式签名（V3.1）、多语言、换行归一化（任何机器克隆即干净）、大量代码级内存/渲染优化。

## 安装
在 **Releases** 页下载 `ADBToolboxGlass-v3.1-.-release.apk` 安装（正式签名）。
> 注：资产名中的 `-.-` 是 GitHub 将中文文件名「稳定版」强制 ASCII 化的结果，即 v3.1 稳定版安装包（`versionName = "3.1"`）。

## 构建
需要 JDK 17、Android SDK（compileSdk 37）：
```
.\gradlew.bat :androidApp:assembleDebug          # 调试版
.\gradlew.bat :androidApp:assembleRelease        # 正式版（签名见 发布声明）
```
